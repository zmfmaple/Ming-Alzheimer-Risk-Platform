# Project: Explainable Alzheimer's Risk Prediction
- Goal: Predict Alzheimer's risk using clinical data + SHAP explanations.
- Features: 
  1. ML Models (Random Forest/XGBoost).
  2. SHAP for individual risk factor analysis.
  3. PDF Report generation.
  4. Web Dashboard (Input 30+ variables).
- Tech Stack: Python, FastAPI, SHAP, Scikit-learn, Streamlit.
